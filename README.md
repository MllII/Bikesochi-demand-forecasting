# 🚴 Bike Demand Forecasting
## Нелинейные модели против сочинской погоды

Прогнозирование почасового спроса на аренду велосипедов для компании **BikeSochi** — оператора городского велопроката в Сочи.

---

## 📌 О проекте

Компания BikeSochi использовала простую линейную регрессию для прогноза почасового спроса на велосипеды. Однако модель часто ошибалась: она видела рост температуры и предсказывала высокий спрос, не учитывая, что **+28 °C под палящим солнцем и +28 °C после дождя — это две совершенно разные ситуации**.

**Цель проекта** — предложить более гибкую нелинейную модель, учитывающую особенности сочинской погоды и нелинейные взаимодействия факторов.

## 🛠 Методология

### 1. Исследовательский анализ данных (EDA)
- Изучено распределение целевой переменной (правосторонняя асимметрия, skewness = 1.16).
- Выявлен «нулевой переключатель» `functioning_day` — при техобслуживании спрос всегда 0 (242/242 наблюдения).
- Обнаружены **нелинейные зависимости**: U-образная температура, пороговый эффект осадков, плато солнечной радиации.
- Корреляции умеренные (макс. 0.57) — ни один признак не объясняет спрос в одиночку.

### 2. Feature Engineering
- Разделение признаков на 3 группы: 8 числовых, 3 категориальных, 4 бинарных.
- Реализован кастомный трансформер `WeatherFeatureEngineer` с методами `fit`/`transform` (ООП, sklearn-совместимый).

### 3. Пайплайн предобработки
ColumnTransformer([
('num', SimpleImputer(median) → StandardScaler, numeric_features),
('cat', SimpleImputer(most_frequent) → OneHotEncoder, categorical_features),
('bin', FunctionTransformer, binary_features)
])

### 4. Обучение и оптимизация
- **kNN Regressor:** `n_neighbors=11`, `weights='distance'`, `p=1`, `leaf_size=21`.
- **Decision Tree Regressor:** `max_depth=10`, `min_samples_leaf=17`, `criterion='friedman_mse'`.
- **Optuna:** 50 trials × 2 модели, единая схема 5-фолдовой кросс-валидации.
- **Метрика:** `neg_root_mean_squared_error`.

### 5. Кросс-валидация
| Модель | CV RMSE | std | CV, % |
|--------|---------|-----|-------|
| kNN (Optuna) | **310.00** | 7.82 | 2.52% |
| Decision Tree (Optuna) | 324.90 | 12.66 | 3.90% |

### 6. Интерпретация важности признаков

2. `time_period_night` — 0.1756
3. `humidity` — 0.1260
4. `time_period_evening` — 0.0860
5. `functioning_day_No` — 0.0842
